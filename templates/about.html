About Unit

UniT (pronounced Uni Taze, a.k.a Унитаз) is a collection of interconnected entries, called a wiki. HTML and Markdown are used as Markup languages.

The project is available on github. It is written in Golang using the net/http. CodeMirror is used as editor. Font Awesome Free serves the icons. The logo licensed under Creative Commons CCBY.
