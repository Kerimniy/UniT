Welcome

This is the home of Унитаз Unit. A minimalistic wiki powered by GO and markdown.

Features

  • Minimalistic interface with dark-mode support
  • Editor with tools for markdown editing
  • User authentication with self-registration
  • Extended Markdown: tables, notes, alerts
  • Header index

Getting Started

Read User Guide, Admin Guide and Markdown Syntax Guide to start using.

Contributing

If you ran into an issue or want to request a feature, please reach out via github. Or fork the repository develop the feature and submit a pull request.

Want to help improve this documentation? Found a typo, a missing section, or have an idea for a FAQ entry? Write an issue.
